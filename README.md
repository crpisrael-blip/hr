# HR — מערכת גיוס והשמה

מערכת וובית לחברת גיוס: אתר ציבורי עם משרות והגשת מועמדות, וממשק פנימי לניהול הגיוס, הלקוחות, המשימות והכספים.

המאגר נמצא בשלב אפיון. אין עדיין קוד.

## מסמכים

| מסמך | תוכן |
|---|---|
| [`docs/SPEC.md`](docs/SPEC.md) | אפיון פונקציונלי ראשוני (גרסה 0.7, טיוטת עבודה): מטרות, גבולות הגרסה הראשונה, משתמשים והרשאות (שישה תפקידים, מטריצה, פרופילים), אזור אישי למועמד, מודל מידע, מפת מסכים, שלושה תרחישים מרכזיים, טבלת מעברי מצבים, מודל מצבים כספי, מנגנון משימות רוחבי, תקשורת יוצאת, התראות, AI, פרטיות, ייבוא, תשתית, קריטריוני קבלה והחלטות פתוחות |

## סדר עבודה מוצע

1. אישור שלושת התרחישים (הגשה באתר, ממועמדות להשמה, התחשבנות וסגירת תקופה).
2. קבלת האקסל לאימות ההתחשבנות, ואז הגדרת שדות לכל ישות.
3. שרטוט המסכים.
4. תוכנית ייבוא והרשאות.
5. משימות בנייה ובדיקות.
